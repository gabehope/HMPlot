# Earthquake catalog for the "earthquakes" gallery example

Source: [U.S. Geological Survey earthquake catalog](https://earthquake.usgs.gov/earthquakes/search/)
through the FDSN event web service, accessed 2026-09-23. USGS data is in the public domain.

`usgs-m45-2015-2024.csv` holds **every event of magnitude >= 4.5 from 2015-01-01 to
2025-01-01 (UTC) with type "earthquake"**: 72,956 rows, sorted by time. It is built by
`scripts/build-earthquakes.py`, which queries one calendar year at a time (the service caps a
query at 20,000 events):

    https://earthquake.usgs.gov/fdsnws/event/1/query?format=csv&minmagnitude=4.5&orderby=time-asc&starttime=YYYY-01-01&endtime=YYYY+1-01-01

`by-year/YYYY.csv` splits it by calendar year for the "provider-earthquakes" example, which loads
one year at a time (`python3 scripts/build-earthquakes.py --split-only` rewrites them without
downloading): columns `month` (1 at the start of the year, 13 at its end, 3 decimals), `lat`,
`lon`, `depth` and `mag` as below.

Columns: `year` (decimal year of the origin time, 4 decimals), `lat` and `lon` (degrees, 2
decimals), `depth` (km, 1 decimal; a few events have small negative depths, above sea level),
`mag` (magnitude of any magType, 1 decimal). Quarry blasts, explosions and events missing a
depth or magnitude are dropped. Rerunning the script can change a few rows as USGS revises
reviewed events.

`usgs-m45-2015-2024.parquet` is the same table as Parquet (zstd, row groups of 20,000), for the
"parquet-earthquakes" gallery example and python/examples/75_parquet.py, written with Polars:

    pl.read_csv("usgs-m45-2015-2024.csv").write_parquet("usgs-m45-2015-2024.parquet", row_group_size=20000)
