# Dumbbell

Two values per category, as points joined by a stem: before and after, or two groups.

## Example

```svelte
<script>
  import { Plot, Legend } from "hmplot";
  import { Dumbbell } from "hmplot/charts";
  const data = { city: ["Oslo", "Lima", "Pune", "Nice", "Kobe"], y2015: [12, 30, 21, 18, 25], y2025: [19, 26, 34, 22, 31] };
</script>

<Plot {data} height={300} axes2d>
  <Dumbbell y="city" x0="y2015" x1="y2025" />
  <Legend />
</Plot>
```

## Options

### Options

- `x0` (`column`): The column of each dumbbell's first value.
- `x1` (`column`): The column of each dumbbell's second value.
- `stem` (`object`): The stems' own props, as one object: {color: "black", width: 1}. They are a Segments, gray and 2 px wide by default.

### Position

- `y` (`channel`): The categories along y, one dumbbell each.

- `fill` (`channel`): The fill color: a CSS color, or a column of numbers or categories mapped to colors.

- `outlineOpacity` (`channel`): Border opacity from 0 to 1: a number, numeric column, array or expression. Fades the border over the fill; mark opacity still applies to both. Missing values hide the border. Default: `1`.
- `outlineWidth` (`channel`): The outline's width in CSS pixels, drawn inside the mark's edge (a point's at most its radius). Default: `0`.

### Scales

## Usage

Each row draws one dumbbell: a point at `x0` and one at `x1`, at its `y` category, joined by a stem. The points take a color per column, so the legend names the two columns.

Dumbbell is a chart: a template over public components, defined in one file, src/lib/charts/dumbbell.js.
