# Manhattan building flyover data

Buildings: [NYC Open Data, BUILDING (5zhs-2jue)](https://data.cityofnewyork.us/City-Government/BUILDING/5zhs-2jue), accessed 2026-09-18. The ground (streets, water, parks) comes from twelve zoom-12 OpenStreetMap vector tiles, the `tile-12-<x>-<y>.mvt` files here (copies of `static/data/vector-tiles/12/`; see its `source.md`: VersaTiles, map data © OpenStreetMap contributors, ODbL, and ESA WorldCover 2021, CC BY 4.0); the example draws them in the buildings' local plane with `VectorTile`'s `origin` and `unitsPerMeter`. Until 2026-09-26 the ground was the Manhattan borough boundary from [NYC Open Data, Borough Boundaries (gthc-hcne)](https://data.cityofnewyork.us/City-Government/Borough-Boundaries/gthc-hcne/data).

The bundled `manhattan-buildings.json` contains **10,000 of the 45,194 BUILDING records whose BIN starts with 1**, the dataset's Manhattan borough code: the first 10,000 of a seeded shuffle of them all, which cover the island rather than a contiguous run of BINs. They include buildings with missing or low roof heights; missing or invalid heights become zero so their footprints remain visible. The example draws them all (`BUILDINGS`, 10,000; a smaller number draws a prefix). The file with all 45,194 (19 MB) stays out of the repository: `scripts/build-manhattan-buildings.py --all` writes it from the downloaded pages, and `BUILDINGS = 45_194` then draws them all.

The official Socrata JSON API query used `$select=the_geom,bin,name,height_roof`, `$where=bin between 1000000 and 1999999`, and `$order=bin`, with pages of 10,000 rows at offsets 0, 10,000, 20,000, 30,000, and 40,000. `scripts/build-manhattan-buildings.py` converts these downloaded pages to the checked-in fixture. Source BIN is the GeoJSON feature ID. `roofFeet` retains the source height in feet; `height` converts it to scene units. Coordinates are projected (below) and rounded to 0.0001 scene units (2.5 cm).

Longitude and latitude are projected to a local Cartesian plane centered on (-73.95, 40.72), at 0.004 scene units per meter. The example exaggerates vertical height by default, with the explicit `type="3d-y-up"` camera preset. `plane="xz"` rotates projected GeoJSON geometry into the horizontal world plane. This local projection is for demonstration, not surveying.
