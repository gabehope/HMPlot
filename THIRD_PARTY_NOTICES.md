# Third-party notices

HMPlot is released under the MIT License ([LICENSE](LICENSE)). It includes, bundles or
redistributes the third-party code, fonts and data below, each under its own license. This file
ships in the npm package (`THIRD_PARTY_NOTICES.md`) and in the Python package
(`hmplot/static/THIRD_PARTY_NOTICES.md`, beside the bundles it describes).

## What each package contains

- **The npm package, `hmplot`:** HMPlot's compiled sources (`dist/`). The dependencies in its
  package.json install from npm as packages of their own, each with its license. Two third-party
  works travel inside it:
  - the jax-js fork, `@hmplot/jax`: jax-js 0.1.25 by Eric Zhang (MIT), with HMPlot's patches,
    bundled as `node_modules/@hmplot/jax` with its LICENSE;
  - the Source Sans 3 font, `dist/fonts/source-sans-3/`, with its license (`LICENSE.md`).
- **The Python package, `hmplot`:** HMPlot's Python code, and two JavaScript bundles built from
  HMPlot's sources and their dependencies: `hmplot/static/widget.js` (the notebook widget) and
  `hmplot/static/standalone.js` (exports and standalone HTML). They contain the packages listed
  under "Code in the Python package's bundles", which includes the jax-js fork, and the fonts
  below. The Source Sans 3 license is also beside them (`hmplot/static/SourceSans3-LICENSE.md`).
- **This repository** also holds the data under "Data", for the docs site, the examples and the
  tests. Neither package contains any of it.
